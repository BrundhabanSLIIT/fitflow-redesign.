# FitFlow Redesign

## Overview
This repository contains the redesigned FitFlow fitness app project. It includes:
- Frontend (React Native)
- Backend (Node.js/Express)
- AI Service (TensorFlow Lite + cloud ML)
- Documentation (tech stack, comparison matrix, architecture diagram, ADR)

## Folder Structure
- frontend/ → Mobile app
- backend/ → API services
- ai-service/ → AI/ML microservices
- docs/ → Supporting documents
